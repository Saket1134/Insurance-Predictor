# 💰 Insurance Premium Category Predictor

A full-stack Machine Learning project that predicts the **insurance premium category** (Low / Medium / High) based on user inputs.

This project combines:
- 🔹 FastAPI (Backend API)
- 🔹 Streamlit (Frontend UI)
- 🔹 Scikit-learn (ML Model)

---

## 🚀 Features

- Predict insurance premium category
- Clean and interactive Streamlit UI
- FastAPI backend for real-time predictions
- End-to-end ML pipeline (preprocessing + model)
- REST API integration

---

## 🛠️ Tech Stack

- Python
- FastAPI
- Streamlit
- Scikit-learn
- Pandas
- NumPy
